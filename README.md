# windows-system-administration-lab

## Overview
A practical Windows 10 laboratory focused on system administration, user management, access control, remote access, and troubleshooting.

## Objectives
- Understand Windows user and group management.
- Configure NTFS permissions and access control.
- Practice remote administration using SSH.
- Explore Windows system configuration.
- Develop troubleshooting skills.

## Lab Topics

### 1. User and Group Management
- Local user accounts
- Local groups
- User permissions

### 2. NTFS Permissions
- File and folder permissions
- Access Control Lists (ACL)
- Permission inheritance

### 3. Remote Access
- Windows OpenSSH
- SSH connections
- Remote command-line administration

### 4. Troubleshooting
- System diagnostics
- Network configuration
- Common Windows issues

## Environment
- Windows 10 Pro
- Oracle VirtualBox
- Windows Command Prompt
- OpenSSH
